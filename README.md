# Смета 3D — калькулятор 3D-печати (FDM и SLA/DLP)

Сайт: калькулятор стоимости 3D-печати и плагин для OrcaSlicer.

- `index.html` — онлайн-калькулятор FDM и SLA/DLP (промышленный SLA). Строит поддержки (лёгкие, средние, сложные) и показывает их на модели, масштаб ползунком. Сам нарезает модель (STL, 3MF, OBJ, STEP) по слоям прямо в браузере, читает G-code из OrcaSlicer, Bambu Studio и PrusaSlicer. Сроки, ночной тариф, доп. услуги, тиражи, текст КП. Настройки хранятся в браузере.
- `plugin.html` — описание плагина «Смета 3D» для OrcaSlicer 2.5 и ссылка на скачивание.
- `download/smeta3d_orca.py` — сам плагин.

Всё работает без сервера: это статические файлы.

## Публикация на GitHub Pages

1. Залейте содержимое папки в репозиторий (ветка `main`).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Скрытый инженерный режим: 5 щелчков по названию, `Ctrl+Alt+E` или адрес с `#engineer`.
